### Архитектурное решение по логированию

**Логирование необходимо для:**
- Shop API
- CRM API
- MES API
- Message Queue(RabbitMQ)

*Комментарий*: Действия и ошибки веб-интерфейса не логируем, т.к. на текущем этапе достаточно Яндекс.Метрик. Риски безопасности из-за публикации систем логирования в интернет выше, чем польза, которую можно получить на текущем этапе.

**Что логируем:**
- Жизненый цикл заказа
- Интеграционное взаимодействие между сервисами
- Действия пользователей
